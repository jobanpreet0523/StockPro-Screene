# Agent Content Policy

All content is educational and draft-only. Every item records sources, factual-verification state, publication date, applicable market date, educational disclaimer, and review history. It must contain no guaranteed return, personalized recommendation, unsupported price/statistic, fabricated testimonial, hidden sponsorship, urgency manipulation, or implication that a provider/broker feature is live without evidence.

Required pipeline:

`Research → Writer → 083 Financial Fact-Checking → 080 Financial Compliance Copy Review → 090 Brand Review → Human Approval → 099 Scheduling Coordinator`

Any factual change after approval restarts fact, compliance, brand, and human review. Private prompts, customer/support data, portfolios, analytics identities, broker data, and unpublished credentials are never content sources. External publishing remains disabled.
