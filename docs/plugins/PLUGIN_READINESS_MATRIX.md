## Guardrail decisions

- AG Grid is intentionally not added: TanStack Table already covers current table requirements and no written gap evaluation exists.
- Novu is intentionally not added: the existing Resend-based notification boundary is sufficient once its server configuration and delivery evidence are completed.
- No Turnstile React wrapper is added: the direct implementation uses Cloudflare's official client and server endpoints and keeps the secret on the Worker.
- No package is removed in this audit merely because it lacks a source import. The retained-unused rows require a separate removal proof that includes scripts, operators, and generated workflows.
- A package declaration, an external project, and a configured production integration are three different states. The matrix never treats one as proof of another.
