# Landing 3D asset manifest

## Ownership and source

All files in this manifest are original StockPro assets created for this repository. The raster fallback is generated by `scripts/generate-landing-3d-assets.py` using geometric drawing primitives. The WebGL scene and static section key frames use procedural Three.js and CSS perspective geometry. No model, texture, screenshot, third-party scene, brand artwork, or external runtime asset is used. The full source/licence record is in `docs/design-research/THREE_D_ASSET_MANIFEST.md`.

The fallback is visible before the lazy scene loads and remains the complete decorative experience when WebGL is unavailable, motion is reduced, the viewport is mobile, memory or CPU hints are low, data saving is enabled, or scene initialization fails.
