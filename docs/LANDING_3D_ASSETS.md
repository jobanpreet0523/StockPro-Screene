# Landing 3D asset manifest

## Ownership and source

All files in this manifest are original StockPro assets created for this repository. The raster fallback is generated by scripts/generate-landing-3d-assets.py using geometric drawing primitives. The WebGL scene and section illustrations use procedural Three.js, SVG, and CSS geometry. No model, texture, screenshot, third-party scene, brand artwork, or external runtime asset is used.

| public/assets/landing3d/stockpro-financial-research.png | Hero | 1280x800 | PNG | 26,221 bytes | Final fallback |

The fallback is visible before the lazy scene loads and remains the complete decorative experience when WebGL is unavailable, motion is reduced, the viewport is mobile, memory or CPU hints are low, data saving is enabled, or scene initialization fails.
