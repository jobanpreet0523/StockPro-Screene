Privacy Policy

Last updated: June 9, 2026. This Privacy Policy details how StockPro F&O Analytics handles your data and privacy protocols.

1. Information Collection and Storage

StockPro F&O Analytics operates purely as an analytical software interface. We do not store, request, or harvest sensitive personal financial credentials or transactional user logs in our database pipelines.

Any user customization layouts, active stock tracker filters, or option strategies built inside our simulated paper calculators remain stored entirely inside local client-side memory mechanisms (such as localStorage) and are not broadcast to external data servers without your explicit consent.

2. API Connections and Telemetry

To power of high-density financial trackers, our interface executes read queries directly against public network feeds (such as the NSE live-data worker endpoints and Yahoo Finance API gateways). No telemetry profiling, transaction routing, or brokerage user session cookies are intercepted or shared during these server-side data calls.

3. Coordinated Security Measures

Our hosting frameworks implement modern transport security layers (specifically TLS 1.3 protocol handshakes) to guarantee that all screen tickers, financial sparkline trends, and option-chain computations load with complete integrity without tampering risk.

4. Cookies and Web Analytics

We utilize standard non-invasive functional session cookies to store visual preferences (such as standard light/dark configuration indicators and preferred underlying asset matrices like NIFTY vs BANKNIFTY) to avoid reset interruptions during rapid screen switching tasks.
